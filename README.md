# 🌐 Project Nexus

> **Tek bir web sitesinde kocaman bir dijital evren.**

Project Nexus; mini oyunlar, şehir kurma, krallık yönetimi, uzay keşfi, dedektiflik, futbol, araba garajı, sanal internet ve gizli görevleri tek bir platformda birleştiren interaktif bir web projesidir.

Amaç sadece bir web sitesi yapmak değil; **kullanıcının içinde vakit geçirebileceği küçük bir dijital dünya oluşturmak.** 🚀
